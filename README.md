# LeagueReplay

简体中文 · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

英雄联盟的本地对局记录与录像复盘工具。整理自己的多账号战绩，收藏其他玩家的对局，通过录像、出装时间线和笔记学习与复盘。

**Windows x64 · 开发预览 · MIT**

## 功能

- 自动记录本机参与的对局，支持手动补录和场次整理。
- 按大区和 Riot ID 查询战绩，关注玩家的近期对局。
- 下载、导入和播放 ROFL 录像，记录时间点笔记与玩家标记。
- 本地保存资料，支持备份、恢复及单场录像与笔记分享。
- 简体中文、英语、日语、韩语界面。

## 使用

需要安装英雄联盟和 WebView2。从 [v0.2.0 预览版下载 Windows x64 安装包](https://github.com/0xMashiro/LeagueReplay/releases/tag/v0.2.0)，或[从源码构建](CONTRIBUTING.md)。当前预览包未签名，尚无自动更新。

1. 登录游戏客户端，启动 LeagueReplay，等待自动连接。
2. 保持软件运行以记录自己的比赛；查找其他玩家时输入大区和完整 Riot ID。
3. 打开对局详情，下载可用录像并添加笔记。备份与恢复在设置中操作。

关闭窗口默认收起到托盘，记录和下载继续运行；在托盘中选择“退出”可停止。

## 地区与录像限制

| 登录状态 | 在线查询范围 |
| --- | --- |
| 未登录 | 仅查看本地已缓存资料 |
| 腾讯服（国服） | 当前大区及已配置的腾讯大区 |
| Riot 服 | 当前大区及已配置的 Riot 大区 |

**腾讯服与 Riot 服不互通，仅安装国服不能查询韩服。** 同运营商跨区查询可尝试，是否成功取决于目标服务，尚未逐区实机验证。请求被拒绝时可登录目标大区重试；空结果不代表玩家不存在。

查询和下载需要已登录的客户端。录像能否下载取决于服务端是否仍提供文件，播放还需要兼容的游戏版本。已缓存资料可离线查看。本工具处理游戏录像，不提供直播视频下载或实时 OB。

时间点笔记跳转需在游戏的 `Config/game.cfg` 中为 `[General]` 设置 `EnableReplayApi=1`。

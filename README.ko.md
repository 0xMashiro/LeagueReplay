# LeagueReplay

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · 한국어

리그 오브 레전드를 위한 로컬 경기 기록 및 리플레이 복기 도구입니다. 여러 계정의 경기를 정리하고, 다른 플레이어의 경기를 저장하며, 리플레이·아이템 타임라인·노트로 배울 수 있습니다.

**Windows x64 · 개발 프리뷰 · MIT**

## 기능

- 이 PC에서 플레이한 경기 자동 기록, 누락된 경기 수동 추가, 플레이 세션 정리.
- 지역과 Riot ID로 전적 검색, 팔로우한 플레이어의 최근 경기 확인.
- ROFL 다운로드·가져오기·재생, 시간 지정 노트와 플레이어 메모.
- 로컬 데이터 저장, 백업·복원, 한 경기의 리플레이와 노트 공유.
- 중국어 간체, 영어, 일본어, 한국어 UI.

## 사용 방법

리그 오브 레전드와 WebView2가 필요합니다. [v0.2.0 프리뷰 Windows x64 설치 프로그램을 다운로드](https://github.com/0xMashiro/LeagueReplay/releases/tag/v0.2.0)하거나 [소스에서 빌드](CONTRIBUTING.md)하세요. 프리뷰 설치 프로그램은 서명되지 않았으며 자동 업데이트는 아직 제공하지 않습니다.

1. 게임 클라이언트에 로그인한 뒤 LeagueReplay를 실행하고 연결을 기다립니다.
2. 앱을 켜 둔 채 플레이하면 내 경기가 기록됩니다. 다른 플레이어를 찾으려면 지역과 전체 Riot ID를 입력하세요.
3. 경기 상세 화면에서 제공되는 리플레이를 다운로드하고 노트를 작성하세요. 백업과 복원은 설정에서 할 수 있습니다.

기본 설정에서는 창을 닫아도 트레이로 최소화되어 기록과 다운로드가 계속됩니다. 중지하려면 트레이에서 “종료”를 선택하세요.

## 지역 및 리플레이 제한

| 로그인한 세션 | 온라인 조회 범위 |
| --- | --- |
| 로그아웃 상태 | 저장된 로컬 데이터만 열람 |
| Tencent(중국 본토) | 현재 서버 및 설정된 Tencent 서버 |
| Riot | 현재 서버 및 설정된 Riot 서버 |

**Tencent와 Riot은 상호 조회할 수 없습니다. 중국 본토 클라이언트를 설치하는 것만으로 한국 전적을 조회할 수는 없습니다.** 같은 운영사의 다른 지역 조회를 시도할 수 있지만, 가능 여부는 대상 서비스에 따라 달라지며 모든 지역에서 실기 검증이 완료된 것은 아닙니다. 접근이 거부되면 대상 지역에 로그인한 뒤 다시 시도하세요. 빈 결과가 플레이어의 부재를 뜻하지는 않습니다.

검색과 다운로드에는 로그인된 클라이언트가 필요합니다. 서버에서 아직 제공하는 리플레이만 다운로드할 수 있으며, 재생에는 호환되는 게임 버전이 필요합니다. 저장된 데이터는 오프라인에서도 볼 수 있습니다. 방송 영상 다운로드나 실시간 관전은 제공하지 않습니다.

시간 지정 노트에서 해당 시점으로 이동하려면 게임의 `Config/game.cfg`에서 `[General]`에 `EnableReplayApi=1`을 설정하세요.

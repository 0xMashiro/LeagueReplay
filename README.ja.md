# LeagueReplay

[简体中文](README.md) · [English](README.en.md) · 日本語 · [한국어](README.ko.md)

リーグ・オブ・レジェンドの対戦記録とリプレイの振り返りを、ローカルで行うツールです。複数アカウントの試合を整理し、ほかのプレイヤーの対戦を保存して、リプレイ・アイテムのタイムライン・ノートで学べます。

**Windows x64 · 開発プレビュー · MIT**

## 機能

- この PC でプレイした試合を自動記録。手動追加やプレイセッションの整理にも対応。
- リージョンと Riot ID で対戦履歴を検索し、フォローしたプレイヤーの最近の試合を取得。
- ROFL のダウンロード・取り込み・再生、時刻付きノートやプレイヤーへのメモ。
- データのローカル保存、バックアップ・復元、1 試合分のリプレイとノートの共有。
- 簡体字中国語、英語、日本語、韓国語の UI。

## 使い方

リーグ・オブ・レジェンドと WebView2 が必要です。Windows インストーラーを使用してください。入手できない場合は[ソースからビルド](CONTRIBUTING.md)できます。プレビュー版のインストーラーは未署名で、自動更新は未対応です。

1. ゲームクライアントにログインし、LeagueReplay を起動して接続を待ちます。
2. アプリを起動したままプレイすると自分の試合を記録します。ほかのプレイヤーを探すには、リージョンと完全な Riot ID を指定します。
3. 試合詳細から取得可能なリプレイをダウンロードし、ノートを残します。バックアップと復元は設定から行います。

初期設定では、ウィンドウを閉じてもトレイに格納され、記録とダウンロードは続行します。停止するにはトレイから「終了」を選びます。

## 地域とリプレイの制限

| ログイン中のセッション | オンライン検索の範囲 |
| --- | --- |
| 未ログイン | 保存済みのローカルデータのみ |
| Tencent（中国本土） | 現在のサーバーと設定済みの Tencent サーバー |
| Riot | 現在のサーバーと設定済みの Riot サーバー |

**Tencent と Riot は相互検索できません。中国本土版のインストールだけでは韓国の対戦履歴は検索できません。** 同じ運営元の別地域への検索は試せますが、利用可否は対象サービスに依存し、全地域の実機検証は完了していません。拒否された場合は対象地域にログインして再試行してください。結果が空でもプレイヤーが存在しないとは限りません。

検索とダウンロードにはログイン済みのクライアントが必要です。リプレイはサーバーで提供されているものに限り、再生には互換性のあるゲームバージョンが必要です。保存済みデータはオフラインで閲覧できます。配信動画のダウンロードやリアルタイム観戦は対象外です。

時刻付きノートから移動するには、ゲームの `Config/game.cfg` の `[General]` に `EnableReplayApi=1` を設定してください。
